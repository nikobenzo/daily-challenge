# Contributing

Daily Challenge is a personal project made by me. The code is public so people can see how it works, but the project is **not seeking outside contributions**, and pull requests will usually be closed without review.

You are still very welcome to help in these ways:

- **Report a bug.** Open an issue with the bug report form, or email [yakovetskyi@icloud.com](mailto:yakovetskyi@icloud.com). Please include your device (iPhone or Mac), the app version from Account, and the steps that cause the problem.
- **Ask a question.** The [support page](https://nikobenzo.github.io/daily-challenge/support.html) answers the common ones. Otherwise, email the address above.
- **Report a security issue privately.** Follow [SECURITY.md](SECURITY.md) and do not open a public issue.

If you want to build the apps yourself, the [developer guide](docs/DEVELOPMENT.md) explains the setup.
